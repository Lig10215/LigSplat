# Security Policy / 安全说明

## Reporting a vulnerability / 漏洞反馈

Please open an issue in this repository or contact qliguangshengq@qq.com. For run-log reports generated by the application, review the preview window before clicking Send — you control what is submitted.

请优先使用本仓库 Issues 反馈，或邮件联系 qliguangshengq@qq.com。使用程序内「报错反馈」时，请在点击发送前审阅预览窗口内容，报告内容由你决定。

## Known distribution characteristics / 已知的发布特征

1. **Embedded report credential / 随包凭据**：`LigSplat-Setup-0.2.0-win64.exe` contains `report-config.private.json` with a Feishu bot webhook and signing key in plaintext. Anyone holding the installer can read it. The credential was **rotated and invalidated before publication**; do not reuse it. Create your own bot or use an author-managed relay if you want error reporting. See §9 of the [software description](https://github.com/Lig10215/LigSplat#9-安全提示请阅读--security-notice-please-read).
   `LigSplat-Setup-0.2.0-win64.exe` 内含明文飞书机器人 webhook 与签名密钥，持有安装包即可读取。该凭据**已在发布前轮换失效**，请勿复用；如需报错反馈请配置自己的机器人或改用作者控制的中继服务。

2. **Self-signed, untimestamped / 自签名且无时间戳**：the installer and executable are signed with a self-signed `CN=Lig10215` certificate and have no RFC3161 timestamp. Windows / SmartScreen may warn about an unknown publisher. Always verify SHA-256 against `SHA256SUMS-0.2.0.txt` in the Release.
   安装包与程序使用自签名证书且无 RFC3161 时间戳，Windows / SmartScreen 可能提示未知发布者。请务必用 Release 中的 `SHA256SUMS-0.2.0.txt` 核对 SHA-256。

3. **Local-first, manual reporting only / 本地优先，仅手动上报**：reconstruction, training, preview and conversion run locally. Error reports are sent only after an explicit user click; no automatic telemetry or model/photo/video upload was observed in static analysis. Static analysis does not prove the absence of other runtime network paths.
   重建、训练、预览与转换均在本机完成；报错仅在用户点击后发送。静态分析未观察到自动遥测或模型/照片/视频上传，但静态分析不能证明运行时绝对没有其他网络路径。
