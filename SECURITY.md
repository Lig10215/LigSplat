# Security Policy / 安全说明

## Reporting a vulnerability / 漏洞反馈

请优先使用本仓库 Issues，或邮件联系 qliguangshengq@qq.com。
Please open an issue in this repository or contact qliguangshengq@qq.com.

## Distribution notes / 发布说明

- 安装包与程序使用 `CN=Lig10215` 自签名证书，且无 RFC3161 时间戳；Windows / SmartScreen 可能提示「未知发布者」。请只从本仓库 Releases 下载，并按 README 第 2 节核对 SHA-256。
- The installer and executable use a self-signed `CN=Lig10215` certificate without an RFC3161 timestamp; SmartScreen may warn. Download only from this repository's Releases and verify the SHA-256 checksums in §2 of the README.
